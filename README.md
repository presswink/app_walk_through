# app_walk_through

A new Flutter plugin plugins for application walk through.

## Getting Started

### clone project

```cmd
git clone https://github.com/presswink/app_walk_through.git
```

add this line in `pubspec.yaml` dependency

```cmd
app_walk_through: ^1.0.0
```
